# Contributing

## Authority

Elijah Lee Cooley is the founder authority for scope, cost, legal classification, visual decisions, and release gates.

## Work Rules

- One Build Room at a time.
- Run the pre-edit Git gate before any mutation.
- Use the authorized branch naming convention for build-room work.
- Keep commits scoped to a single approval boundary.
- Validate the changed slice before moving on.
- Record evidence and limitations with the work.
- Preserve docs/source byte-for-byte.
- Do not expand cost, deployment, scope, or dependencies without approval.

## Branching and Validation

Branch work must remain on the approved build branch until the founder authorizes a later phase. Validation must be explicit, repeatable, and attached to the affected slice.

## Prohibited Expansion

Do not scaffold application code, create unapproved infrastructure, or introduce backend, payment, analytics, AI, or deployment systems outside the authorized build room.
