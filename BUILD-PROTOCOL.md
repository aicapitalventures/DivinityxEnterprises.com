# Build Protocol

This project adopts AICV Universal Lean Build Protocol™ v1.0 as the governing execution protocol.

Preserved source: [docs/source/AICV-Universal-Lean-Build-Protocol-v1.0.md](docs/source/AICV-Universal-Lean-Build-Protocol-v1.0.md)

The source protocol is authoritative and must not be rewritten, weakened, or paraphrased into a different standard. This repository may summarize its project-specific application, but the source canon remains the preservation record.

For Build Room 01, the protocol means:

- one controlled build room only;
- founder authority before scope expansion;
- no paid cost without approval;
- no application scaffold;
- no dependency installation;
- validated changes only;
- evidence recorded alongside the work;
- protected source unchanged.
