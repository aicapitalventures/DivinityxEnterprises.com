# Architecture Decision Records

Use this directory for formal ADRs only. Do not create speculative ADRs.

## Index

- ADR-0001: Enterprise Portfolio Taxonomy and Public Information Architecture Lock

## Required ADR Format

- ID
- status
- context
- decision
- alternatives
- cost effect
- consequences
- reversal path
- founder approval

Each ADR must be concise, dated, and tied to a specific repository decision.
